# Vertical-scoped execution migration

Approved 2026-07-26: a vertical is an independent product slice that owns an internal DAG of one or
more EDs. The prior relationship, one VD to one ED, is superseded for new work.

Legacy ED-004 remains verified historical evidence. New work uses `ED-VNNN-NNN` identifiers and
explicit `vertical: V-NNN` membership after the directive framework releases the corresponding
intake/runtime support.

The V-005/V-006/V-007 one-ED authoring attempts were stopped before greenlight. V-007's partial
ignored scaffolding is retained as non-authoritative reference and replaced by V-007's two-ED
backlog.
