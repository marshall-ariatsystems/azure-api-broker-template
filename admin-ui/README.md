# Hosted connections and access console

Administrators sign in through the hosting service and use the browser console to connect an identity provider, create a connection, grant or revoke access, and review health, usage, and audit outcomes.

Credentials are write-only. A submitted value is sent to the server-side credential sink and is cleared from the form immediately; it is never displayed by this console.

The console uses same-origin JSON endpoints and a trusted server-side administrator context. It does not provide provider-specific policy editing or credential readback.
